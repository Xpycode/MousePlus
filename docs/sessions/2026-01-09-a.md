# Session: 2026-01-09-a

## Focus
Discovery interview + Architecture mapping for MousePlus

## What Happened

### Part 1: Discovery Interview

1. **Ran discovery interview** - established core requirements:
   - Radial/ring menu triggered by hotkey (user uses BetterMouse for MX Master buttons)
   - Personal use but planning to publish
   - Menu bar app with settings window

2. **Researched existing solutions:**
   - [Pie Menu](https://www.pie-menu.com/) - expensive, app-specific shortcuts
   - [Pieoneer](https://apps.apple.com/us/app/pieoneer/id6739781207) - beautiful but limited features
   - [menuanywhere](https://github.com/acsandmann/menuanywhere) - reference for menu bar access feature

3. **Defined unique value proposition:**
   - Unified quick-access hub (not just pie menu)
   - Nested actions (app switcher as sub-menu)
   - Clipboard integration
   - Menu bar access with search
   - Beautiful but functional aesthetic

### Part 2: Architecture Mapping

4. **Evaluated technical options:**
   - Overlay window: NSPanel vs SwiftUI Window vs NSWindow subclass → chose **NSPanel**
   - Global hotkey: CGEvent tap vs NSEvent monitor vs libraries → chose **NSEvent.addGlobalMonitorForEvents**
   - Menu bar access: only option is **AXUIElement API** (requires Accessibility permission)
   - App switching: **NSWorkspace.runningApplications** (simple, no extra permissions)

5. **Made additional decisions:**
   - Animation: user-selectable (instant vs animated)
   - Dismiss: all methods (click outside, Escape, release hotkey)
   - User approved Accessibility permission requirement

6. **Defined project structure** - see CLAUDE.md for full layout

## Decisions Made

See `decisions.md` for full entries:
- Menu depth: 2 levels
- Trigger: both methods
- Persistence: config only
- Style: beautiful but functional
- App presence: menu bar + settings window
- Overlay: NSPanel + SwiftUI
- Hotkey: NSEvent.addGlobalMonitorForEvents
- Menu access: AXUIElement API
- Animation: user-selectable
- Dismiss: all methods
