## Decisions

- Preserve BetterMouse → ⌃⌥⌘M and the disabled direct MousePlus mouse binding throughout the
  visual checks so button 5 continues to suppress Warp tab navigation.
- App-specific HUDs use one complete inner/middle action layout per bundle identifier, created as an
  independent copy of Global. Triggers, geometry, menu/ring appearance, motion, and behavior remain
  global; item-level overrides stay with their items.
- Normal keyboard/mouse bindings are Contextual routes. A distinct Global HUD keyboard shortcut is
  unbound by default, supports the established trigger modes, and bypasses app resolution.
- Contextual resolution freezes the frontmost app's bundle ID/PID and selected layout for one
  invocation. Missing, unavailable, or self profiles fall back to Global.
- Switching routes in a visible HUD preserves its pointer anchor, resets interaction/outer state,
  and transfers release ownership so an old gesture cannot execute a new layout.
- The older app-aware command-ring plan no longer owns the assumption that Rings 1 and 2 are always
  global. Its menu browsing, search, pagination, and pinning ideas remain separate future work.
- Compatibility saves merge known typed action fields into their original raw JSON recursively.
  Identifier occurrences are consumed once, so malformed duplicate IDs cannot cross-contaminate
  distinct future fields.
- Explicit backup recovery replaces the entire encoded app-profile storage boundary; ordinary
  edits continue to use typed three-way merging against a fresh disk base.
- The Contextual and Global keyboard recorders apply one normalized exact-collision policy, and a
  monitor emits release only for a key-down it accepted.
- In-place HUD replacement reuses the panel and host but advances a native-input generation. Pointer
  sequences from the previous layout are rejected, while an auxiliary mouse button that triggered
  the replacement is explicitly adopted by the new generation.
- The center remains one native Settings action. Its identity image and name describe the frozen
  resolved context; the gear is decorative, excluded from accessibility, and click-through so the
  original target and drag arbitration own the entire center frame.
- Trigger live-apply compares each effective monitor binding independently. A genuinely replaced
  held binding emits an explicit cancellation before its monitor stops, allowing invocation
  ownership to dismiss safely instead of waiting forever for a native release that cannot arrive.
