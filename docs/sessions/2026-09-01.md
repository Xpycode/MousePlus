## Decisions

- **Chosen direction: Solution 1 — a unified sidebar Settings workspace containing the Menu Items editor.** MousePlus will use the shared `MacUIKitSettings` sidebar shell pattern and bring ring preview, item editing, ShortcutKit recording, Test Action, save state, and errors into one configuration surface.
- The separate-editor-window alternative is rejected as the target design because it preserves the two-window handoff that made editing and verification cumbersome.
- The current T12 gate is superseded by a UX-unblock sequence: specify the unified workspace first, plan it in the following session, then implement before reducing T12 to a short smoke test.
- The specification keeps one authoritative configuration-editing boundary: load/decode failure cannot feed an automatic defaults write, Saved means durable persistence, and live apply follows successful persistence only.
- The final T12 gate becomes automated model/persistence coverage plus one short live smoke test spanning edit, save, keystroke test, reopen, and live-ring invocation.
- Unknown action raw values must round-trip losslessly; Test Action flushes before execution; failed close offers Retry/Discard/Cancel; contextual tests name a safe external target; backups survive relaunch.
- Shared shell and ShortcutKit recorder controls are narrow exceptions; app-owned controls migrate to AppKit wrappers. Package use pins an exact clean revision.
- Ordinary shortcut conflicts warn; only reliably unusable/reserved shortcuts block visibly. Live-ring failures use a non-activating HUD; successes remain silent.
