## Decisions
*(Config/setup, not architecture — not logged to decisions.md.)*
- **Trigger = modifier chord (`⌃⌥⌘M`), mapped from a mouse button via BetterMouse.** Avoid bare/fn function keys — the Logitech firmware remaps them (F4→F12). Saved to project memory `trigger-modifier-chord-strategy`.
- Show trigger modifiers as **text, not glyphs** (legibility).

### Removed the hard-coded test default trigger
- `TriggersConfig.default` shipped an F5 tap-toggle + middle-click hold-release test pair. Removed it → now ships **unbound** (`TriggersConfig()`, both `.none`); the user binds via the Triggers tab (W4) or onboarding (D1/W5). Saved `config.json` still wins at load, so existing users unaffected.
- **⚠️ Onboarding gap flagged:** onboarding isn't built, so a fresh install now has no trigger and no guided way to set one (only Settings → Triggers → Record). Noted in PROJECT_STATE Current Focus + elevated W5 (item 23) to load-bearing.

### Fixed a hard crash on selecting an outer-band sub-item
- **Symptom (user report):** triggered ring → Apps → Safari; HUD closed, Safari didn't open, and the app was dead afterward (next trigger did nothing).
- **Root cause:** `RingMenuView.outerBand` used `ForEach(0..<viewModel.outerItems.count, id: \.self)` — a constant-range ForEach SwiftUI snapshots at graph-build time. Committing a sub-item clears `outerItems` to empty, but the view re-rendered the stale indices into the emptied array → **"Index out of range"** `EXC_BREAKPOINT` (crash log `MousePlus-2026-05-31-034021.ips`, faulting frame `closure #1 in RingMenuView.outerBand.getter`). The crash on the main render thread also killed the in-flight `appSwitch` Task, which is why Safari never activated.
- **Fix:** iterate items keyed by stable `id` — `ForEach(Array(outerItems.enumerated()), id: \.element.id)` — binding the item from the current snapshot instead of subscripting. Arc-offset `index` still flows to the geometry. `inner`/`middle` bands use `0..<spokeCount` (stable per session) → never at risk.
- **Verified live:** ring → Apps → Safari now activates Safari, no crash, app stays alive.
