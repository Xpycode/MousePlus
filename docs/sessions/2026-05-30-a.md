### Discovered / Bugs fixed during verification
- **App quit on last-window-close** — LSUIElement app whose only SwiftUI scene is `Settings`; closing the auto-opened "Identify Input" window terminated the app and killed the global trigger. Fixed with `applicationShouldTerminateAfterLastWindowClosed -> false`; made that window `.miniaturizable`.
- **Escape didn't dismiss** — `DismissMonitor` used only a global key monitor, which can't see Escape when our own panel holds focus (click-outside worked because a global mouse-down is inherently to another app). Added an `addLocalMonitorForEvents` keyDown monitor for Escape (local XOR global per event → no double-fire), swallowing the handled Escape.
- **F5 trigger collides with the system/Perplexity voice key** on a bare press — use Fn+F5 directly, or map a mouse button to F5 (sends the raw keycode). F5 is a temporary test trigger until the Triggers settings tab lands.
- SwiftUI `/preview` harness can't render this multi-file macOS view (standalone/iOS-sim only) — verification was by clean compilation per wave + live hands-on testing, not preview capture.
