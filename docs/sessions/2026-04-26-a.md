### Discovered
- The original `Config/PointerActions.entitlements` file was effectively empty (`<dict/>`). This is almost certainly **part of the hotkey blocker** from January — without an Accessibility entitlement entry, the system never prompts the user to grant the permission that NSEvent global monitor needs.
- `01_Project/PointerActions.xcodeproj/xcshareddata/xcschemes/` was empty — Xcode hadn't created a shared scheme yet. The implicit scheme will be regenerated on next open.
- Project was not previously a git repo. Now is.
- Codebase uses Xcode 16's PBXFileSystemSynchronizedRootGroup (buildable folders) — files auto-sync from disk, which made the rename much cleaner than legacy pbxproj file references would have been.
