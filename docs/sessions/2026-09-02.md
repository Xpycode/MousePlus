## Decisions

- Shortcut recording uses an active Quartz event tap because a passive/global monitor cannot prevent the target application from also handling the chord.
- The menu editor owns persistent selection; its embedded runtime ring is render-only and cannot update selection from hover or gestures.
- HUD customization resolves through explicit, tolerant configuration: independent inner/middle auto or fixed counts and offsets; menu defaults with ring overrides for icon orientation; and application → menu → ring → item color inheritance.
- Outer-ring visibility has always-visible, outward-crossing reveal, and always-hidden modes. Conditional reveal crosses the inner outer edge after first entering it and latches for one invocation; always-hidden submenu parents remain preserved but unavailable rather than executing a marker action.
- Requested colors remain persisted as sRGB RGBA while the renderer derives deterministic contrast-safe output. Preview interaction moves to one AppKit-backed surface sharing runtime geometry and cannot reach action execution.
- HUD customization, item arrays, and item color overrides form one editor-owned persistence field so reset, recovery, and fresh-base merging remain atomic without overwriting unrelated Settings fields.
- Hold-release commits through the global trigger-up path while tap-toggle re-hit-tests its final in-panel release location; the paths remain exclusive to prevent double or stale commits.
