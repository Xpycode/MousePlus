### Wrote `docs/HUD_ACTIONS_PLAN.md`
Proper task specs for all five + a **shared foundation** layer + recommended build order.
Key cross-cutting findings:
- **Shared foundation (~1–1.5 d, build first):** extend `ActionType`; async `expand()` w/
  stale-guard (dynamic outer ring); `IconSource` enum for real app icons (no NSImage in the
  Codable model — pass to `WedgeView`, side-dict by item id); one shared Accessibility-TCC
  flow (pre-prime in Settings, never mid-gesture); dismiss-before-action seam (`requestClose`
  at `RingViewModel.swift:132`).
- **Build order:** foundation → Window snap (~2d, most radial-native, self-contained) →
  Screenshots (~0.5–1d, interactive modes need no TCC) → Menu mirror (~1.5–2d, differentiator,
  ports from menuanywhere) → App switcher (~1.5–2d, builds IconSource/async) → System toggles
  (~3.5–4d, most permission surface). ≈10–13 dev-days total at v1.

## Decisions (to log in decisions.md — not yet committed)
- **Drop `ActionType.clipboard`** — user is building a separate clipboard app (ClipSmart/Aloft);
  bridge to it via app-switch/custom instead of reimplementing.
- **Menu mirror** = radial top-level + native `NSMenu` handoff (B1); `AccessibilityService` is
  `@MainActor` (NSMenu is main-thread-affine), not an actor; `kAXPressAction` only on the leaf
  after `activate()` + 0.1s.
- **Window snap** = own middle wedge → outer arc of 8 directions; `actor WindowService`;
  size→pos→size set order + `AXEnhancedUserInterface` toggle; y-flip about the **primary**
  screen's `frame.maxY` (Rectangle's hacks, verbatim).
- **App switcher** = self-tracked MRU via `didActivateApplicationNotification` (no public
  z-order API); `IconSource` enum, NSImage never in the Codable model; existing macOS-14
  `activate()` is already correct.
- **System toggles** = dedicated `ActionType.systemToggle` w/ curated enum (no arbitrary
  shell); `Process`→`osascript`, not `NSAppleScript`; v1 set = dark mode, display sleep, screen
  saver, volume/mute, lock screen (CGEvent ⌃⌘Q, not private `SACLockScreenImmediate`), empty
  trash. **Defer** DND/Focus (no reliable API) + brightness (private only).
- **Screenshots** = interactive `screencapture -i/-U` only for v1 (NO Screen-Recording TCC —
  user's drag is consent); `ScreenCaptureKit` reserved for a future silent/sandboxed backend.
- **Product:** Features menu-mirror / window-snap / system-toggles are **sandbox-incompatible**
  → reinforces the direct-distribution path; keep each behind its service so a sandboxed
  target can compile them out.
