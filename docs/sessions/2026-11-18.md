## Bugs found (open — next session)

1. **Menu Items preview shows built-in sample ring while status says "Saved".** Screenshot: Global
   HUD selected; preview shows exactly `RingMenuItem.sampleInnerItems`/`sampleItems` (Copy, Paste,
   Mission Control, Spotlight / Apps, Snap, Menu, Custom, no colors). Saved `config.json` and the
   live HUD both show the user's custom Global menu (6 inner incl. 3 colored, 8 middle incl. 4 "New").
   Facts: the only config writer is Settings; no Reset backup exists (Reset never used); current
   process started 11:09, file last written 11:11. Saves merge only dirty fields into a fresh disk
   read, so a triggers-only save could leave menu items intact even with a stale editor.
   Candidate paths (unconfirmed):
   - Preview `RingViewModel` (`RingPreviewSelector.swift:162`, defaults to sample items) not
     receiving editor items via `onChange(of: previewContent, initial: true)` (`:204`).
   - Editor `MenuEditorModel` (seeded with samples, `SettingsWorkspaceCoordinator.swift:69`) not
     reloaded; `SettingsView.task` skips `load()` once `isLoaded` (`SettingsView.swift:62`).
     If the editor itself holds samples, the next Menu Items edit would overwrite Global items
     (`merge`, `SettingsWorkspaceCoordinator.swift:~490`).
   - Also: `ConfigurationService.loadResult` treats a missing file as a successful load of
     defaults and Settings marks it "Saved" (`ConfigurationService.swift:57`).
   The user had added an app HUD (Safari) before seeing it; that is the leading repro lead.
   Diagnostic not yet done: Selected Item inspector contents, and Global→Safari→Global switch.
2. **Key names use a hard-coded US layout.** `Utilities/KeyCodeNames.swift:20` maps key code 42 to
   `\`. On the user's German keyboard that key is `#`, so a correctly recorded Command-Shift-#
   (Safari Tab Exposé; saved as keyCode 42, modifiers 0x120000) displays as Command-Shift-\ and
   looks like a failed recording. Fix: derive labels from the current input source
   (`TISCopyCurrentKeyboardLayoutInputSource` + `UCKeyTranslate`), with the table as fallback.
